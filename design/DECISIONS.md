# Approved decisions

1. Direction 01, Familiar: icy blue sidebar, white conversation, blue outgoing messages, readable navy text, soft sea avatars. Adapt semantics for dark mode.
2. Regular lowercase **jelly** in Nunito 900. The j is an ordinary letter. Earlier jellyfish-j explorations are rejected.
3. Logo 05, Friendly bell: standalone cyan/blue domed jellyfish, two navy eyes, three soft tentacles. The original approval image is `brand/logo/approved-reference.png`.
4. Twelve distinct sea creatures for agent identity. Names and textual statuses remain the primary identification and state cues.
5. Gentle working jellyfish only while work is active. Pause for handoffs and respect reduced motion. A single brand-button bob is an optional, user-triggered Easter egg.
6. Projects are optional and flat. All agents and Ungrouped are views, not stored projects. One agent belongs to zero or one project.
7. Project folders are selected on the connected server. New project agents inherit the current default folder exactly. Existing agents keep their cwd when defaults, membership or project existence change.
8. Projects share files, not conversations or runtime sessions. Directory selection is not a permission sandbox.
9. Mobile has separate full-width list and chat views, with direct project switching from both. No permanent narrow rail.
