# Jelly design direction prompts

Generated with the built-in imagegen tool. All screen content is illustrative.

## Direction 1

Use case: ui-mockup.
Create an exceptionally polished, high-fidelity product design presentation board for Jelly, an existing local AI-agent chat application. This is a NEW DESIGN PROPOSAL, not a screenshot of an implemented app.
The current app has a desktop agent sidebar (Jelly / General assistant, create agent, Archived agents, This computer / Connected locally), a conversation header (agent identity, Ready, Computer), threaded user and assistant messages, tool activity, a model selector and message composer. On current mobile its permanent 78px side rail wastes space. Redesign these coherently; retain the agent-centric product model. Use illustrative agents Jelly, Research, and Studio, not human contacts. Preserve access to Computer and connection settings.
Deliver ONE landscape board, very high resolution, approximately 2400 by 1350. Three non-overlapping, front-facing flat UI screens: large desktop on left, mobile agent-navigation screen in middle, mobile conversation screen on right. Desktop about 1320x880 screen ratio, phones about 390x844 ratio. Give each screen readable scale; show complete screens with bottom composers and safe-area padding. No perspective devices, no hands, no laptop hardware. Board has generous but economical margin and a small concept title at top, captions below each screen. UI takes at least 85% of area. Sharp typography, professional optical spacing, restrained shadows, realistic 44px mobile touch targets. Mobile chat is edge-to-edge with NO permanent side rail and no horizontal overflow.
Show equivalent sample content across desktop and mobile: selected Jelly / General assistant. User: "Help me plan a calmer week." Assistant: "Let's make room for what matters." Then short easy-reading suggestions "Protect two focus mornings." "Keep Friday afternoon open." and a small preview card titled "A lighter week", with "3 priorities · Draft". A subtle collapsed activity row "Reviewed your notes" can precede the answer. Desktop agent list: Jelly / A lighter week; Research / Three sources ready; Studio / Your moodboard is ready. Make previews and status distinguishable. Add agent action, search, archive and settings access thoughtfully; no irrelevant analytics dashboards.
Composer says "Message Jelly", plus button and circular up-arrow send. Use familiar Messages-inspired spatial grouping and ChatGPT-inspired readable assistant prose, but create a distinctive original Jelly interface. Brand wordmark is "jelly". No Apple or OpenAI logos. No stock photos, no gratuitous gradients, no illegible microtext, no dense technical logs, no oversized marketing copy.
DIRECTION 01 — "Jelly / Familiar". Apple Messages-inspired, brilliantly simple native feeling. Almost-white cool surfaces, near-black text, precise blue accent #1672F8, circular pastel agent monograms. Desktop uses a 290px full-height softly tinted inbox sidebar, large "jelly" wordmark, small compose icon, inset Search field, stacked 76px agent rows with title, one-line message preview, subtle time and small unread dot. Selected row is a pale blue pill with strong text. Fine separators confined to list. Sidebar bottom has discreet "This computer · Connected" and gear. Chat header thin and quiet with Jelly identity, Computer action and ellipsis. Chat content uses a right-aligned bright blue user bubble, assistant prose directly on white canvas and a simple paper-like week preview. Lots of breathing room, compact pill composer anchored low. MOBILE NAVIGATION is a full-screen Messages-like agent inbox with large "Agents" title, search, agent rows and bottom "This computer · Connected". MOBILE CHAT is a separate full-screen pushed conversation: back chevron labelled "Agents", Jelly title and small circular avatar, Computer icon inside overflow-friendly header. Bottom single-row rounded composer with plus outside. Express precision, warmth and familiarity. Board background very pale cool gray. Caption: "A familiar home for your agents."
