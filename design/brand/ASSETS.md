# Assets and provenance

- `logo/approved-reference.png`: original approved variation 05 from ImageGen.
- `logo/jelly-mark.png`: ImageGen transparent extraction of that reference. Retains dimensional highlights and friendly eyes.
- `logo/jelly-monochrome.png`: ImageGen single-colour adaptation for simple reproduction.
- Horizontal, inverse, stacked, app-icon and favicon SVG files are **hybrid exports**: embedded raster character with outlined vector lettering/shapes. The wordmark-only SVG is vector. They are not claimed to be fully vector jellyfish drawings.
- `avatars/`: twelve ImageGen illustrations; the complete prompts and original collection remain in `archive/jelly-sea/`.
- Nunito variable font from the official Google Fonts `ofl/nunito` directory. SIL Open Font License included in `fonts/OFL.txt`; source listing retained in `fonts/source-index.json`.
- UI icons: Lucide, ISC license in `../ui-kit/ICONS-LICENSE.txt`. Production uses the existing lucide-react package.
- Motion recipes: transitions.dev public skill, retrieved 23 September 2026. References preserved under `../implementation/transitions/` with source links in `../implementation/plan.md`.

Production copies are under `public/brand/`. Raster source assets are retained at full resolution. Browser rendering scales them without modifying the original art.
