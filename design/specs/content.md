# Interface copy

| Situation | Copy |
| --- | --- |
| Empty project | A fresh space for your ideas. / No agents in [project] yet. |
| No project | Ungrouped |
| Folder identity | Folders on [instance] · Jelly server |
| Folder inheritance | Used by new agents. Existing agents keep their working directories. |
| Unavailable folder | This folder is missing or inaccessible on the Jelly server. Choose another folder. |
| Duplicate name | A project with this name already exists. |
| Pending work | [Agent] is working… |
| Handoff | [Agent] is waiting for your help… |
| Stop pending | [Agent] is stopping… |
| Project removal | Agents move to Ungrouped. Conversations, files, and working directories stay unchanged. |
| Reconnect | Reconnecting to Jelly. Work continues on the server. |

Keep warnings actionable. Avoid sea puns and technical implementation terms in ordinary navigation. Filesystem paths remain explicit because they affect where the agent executes.
