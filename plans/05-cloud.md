# Phase 5 — Jelly Cloud

- [ ] Build account creation and billing for managed Jelly instances.
- [ ] Provision a VM with Jelly pre-installed and securely connect the customer to it.
- [ ] Provide instance lifecycle controls, health reporting, backups, restore and updates.
- [ ] Add hosted instances to the client connection/switcher flow.
- [ ] Provide a hosted web client for customers who do not install a local client.
- [ ] Validate customer/VM isolation, access revocation, provisioning failures and billing/lifecycle consistency.

Keep cloud management separate from the Jelly server inside each VM. Preserve independent local and self-hosted use.

## Exit criteria

A customer can sign up, provision and connect to an instance, manage its lifecycle and billing, and restore its data from a backup.
