# Phase 6 — iOS companion

- [ ] Build a mobile client that connects to reachable local, self-hosted and Jelly Cloud servers.
- [ ] Provide instance switching, agent messaging and activity review on mobile.
- [ ] Add notifications and mobile responses to requests for input, including an appropriate experience for browser/password handoffs.
- [ ] Handle intermittent connectivity, backgrounding, expired sessions and resumed activity without duplicating actions.
- [ ] Verify the experience on a physical iPhone against local, self-hosted and hosted instances.

## Exit criteria

Users can check agents and continue work from their phone while execution stays on the selected Jelly server.
